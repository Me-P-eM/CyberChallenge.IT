## Tool e Prerequisiti

Per utilizzare al meglio il materiale è utile avere familiarità con:

- Linux/Unix command line
- Linguaggi di programmazione
- Tool di base per CTF (Burp Suite, Wireshark, GDB, Ghidra, etc.)
- Ambienti virtualizzati (Docker, VM)

Inoltre, è presente uno [script](/CyberSecNatLab%20-%20VM%20Setup.sh) di installazione di alcuni tool utilizzati durante il corso.

Durante la gara nazionale di Attacco/Difesa, abbiamo utilizzato **Caronte** per lo sniffing del traffico e **DestructiveFarm** per l'esecuzione degli exploit.
